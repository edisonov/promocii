# Промоции в магазините

Мобилно-ориентирано уеб приложение (PWA) с актуалните промоции в **Lidl, Kaufland и BILLA** за София.

- Филтри по магазин и категория, търсене, сортиране
- Цена за единица (€/кг, €/л), топ оферти, изтичащи скоро
- Списък за пазаруване с отметки (пази се на устройството)
- Работи офлайн с последните данни, инсталира се на телефона

**Данни:** `data.json` се обновява всяка сутрин от автоматичен агент.
Хоства се чрез GitHub Pages. Пакетира се в Android приложение (.apk) чрез PWABuilder.
